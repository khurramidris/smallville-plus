# Connected realism implementation: batch 1

**Evidence label: fixture only.** Every MockLLM-derived behavioral, cost, token,
runtime and storage number in this report is fixture only. Tests demonstrate
engineering correctness; no paid-model milestone is completed by these results.
Historical implementation status below predates the [M0–M4 rules](../MILESTONES.md).

Date: 2026-10-22  
Scope: R0 measurement foundation and a bounded subset of R1  
Inference: deterministic MockLLM only; no network or provider API

## What changed

The world now stores owner-scoped knowledge evidence separately from memories.
Campaign records carry the subject, candidacy status, whether the owner was
exposed or has accepted self-knowledge, the source, timestamps, confidence and
the retained memory ID. A read phone message can create exposure; delivery alone
cannot. Testimony never becomes world truth. The earlier phrase-based diffusion
metric remains in reports so historical results are still interpretable.

Evaluation reports use protocol `realism-eval-v1` and record the seed, backend,
models, realism profile, population digest, horizon, benchmark and measurement
definitions. LLM ledger rows now include request purpose. Intention and perception
events expose plan/action/reflection outcomes and interaction opportunities.
Campaign interviews collect a separate recall answer, but awareness remains null
until a human assesses the claim and evidence.

The `connected_v1` profile requires a validated population artifact containing
life histories and at least 14 days of private digital history. Residents receive
durable, owner-scoped initial goals outside their bounded memories. Retrieval uses
the current task and question, active goals, location, nearby residents, low needs
and upcoming calendar entries. Relevant personal relationship values are visible
to the resident's own decision context.

Memory remains finite and fallible. Source identity is protected from routine
event floods, identical recent GM outcomes coalesce with a repetition count, and
retrieval ranks a bounded set rather than exposing the whole stream. This is a
local lexical implementation; no semantic or graph-memory service was added.

## One-day connected-profile smoke run

The fresh population contains 25 residents, 21 history days, 1,050 messages,
75 calendar entries and 75 generated initial goals. Its digest is:

`ddf8133c5210546ae26205b0f5971e9a856a85ff09ec9f34935daf43da157f09`

The final Phase 3 optimized run completed all 1,440 requested minutes in 70.716 seconds.
It made 761 MockLLM calls: 608 actions, 128 plans and 25 reflections. There were
no uncertain calls and cost was $0. Synthetic fixture token counts were 3,313,191
input and 39,183 output; these are not provider usage estimates.

The final evidence ledger contains eight campaign records across five exposed
residents. Only Sam has accepted self-knowledge; third-party testimony remains
exposure. Historical retained-memory diffusion reports 4 residents for Sam's
campaign and 10 for the party. These outcomes are diagnostics, not realism gains.
The party is scheduled for day two, outside this smoke horizon.

The run produced 4,030 events. Replay generated byte-identical event JSONL with
SHA-256:

`b1f5eeabcfd36fbe5dca2729cea97f2504b607aebf7daa0a271b823351271f51`

Agent, goal, knowledge, message, calendar and metadata projections also match.
The source event file is 41,675,392 bytes and the SQLite world is 45,727,744 bytes.
Full snapshots therefore remain a material replay and scale cost.
An earlier run generated the same event hash in 42.987 seconds, demonstrating
that shared-host wall time is descriptive rather than a stable benchmark.

## What this does not establish

This batch does not prove that Smallville+ is more believable or realistic than
Park et al. MockLLM is a deterministic fixture, the generated histories are
fictional, and no matched human evaluation was run. Initial goals influence
context but cannot yet be revised, blocked, completed or abandoned through a
dedicated transition. Expired non-seed episodes are not archived. Plan repair is
still whole-plan fallback rather than local future-block repair.

The generated history templates also need connected household, work and friend
episodes with unfinished obligations. There is still no consent-based multi-turn
spoken interaction, asymmetric trust model or typed exchange of help/items. Those
are the remaining R1 work and R2/R3 gates in `REALISM_PLAN.md`.
